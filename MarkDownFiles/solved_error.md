# Error: ModuleNotFoundError: No module named 'rmip'

## Symptom
```
python3.9 -m src.rmip.cli reduce 1 --db project.db --method DRG ...
ModuleNotFoundError: No module named 'rmip'
```

## Root cause
Running via `python3.9 -m src.rmip.cli` treats `src` as a package, but RMIP
imports itself as `rmip` (not `src.rmip`).  The `src/io/` subpackage also
shadows stdlib `io` if `src/` is on `sys.path` incorrectly.

## Fix
Always use the repo-root launcher `rmip_cli.py`:

```bash
cd /data/OPEN_CODE/PHASE-3

# Correct
python rmip_cli.py reduce 1 --db project.db --method DRG --target "H2,O2,H2O" --eps-max 0.5 --out drg_steps.json

# New commands (Phase 5B extended)
python rmip_cli.py reduce 1 --db project.db --method DRGPSA --target "H2,O2,H2O" --sa-json sa_data.json --out drgpsa_steps.json
python rmip_cli.py reduce-viz 1 --db project.db --reduction-json drg_steps.json --mode both
python rmip_cli.py reduce-viz 1 --db project.db --reduction-json drg_steps.json --mode coeff --export-html coeff_viz.html
```

The `python -m pytest src/rmip/tests/ -v` invocation is fine because
`conftest.py` adds `src/` to `sys.path` correctly for pytest only.
